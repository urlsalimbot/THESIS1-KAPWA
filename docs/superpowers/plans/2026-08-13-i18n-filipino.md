# Filipino (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Filipino language support to the KAPWA frontend (kapwa-client) — English default, user-toggleable, all modules translatable, offline-safe.

**Architecture:** react-i18next with statically bundled TypeScript locale modules (`src/i18n/locales/en|fil`). English is the canonical source; `i18next-parser` extracts keys from code, a conversion script emits the typed `en` TS module, and `fil` mirrors it. Locale choice persists in `localStorage['kapwa-lang']`; toggle lives in the Topbar user menu and Settings. Server-value display maps (case status, category, …) translate via `t('status.<raw>', { defaultValue: raw })` so unknown values pass through.

**Tech Stack:** React 19, Vite 8, TypeScript 5.7 (strict), i18next, react-i18next, i18next-parser (dev), vitest + @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-08-13-i18n-filipino-design.md`

## Global Constraints

- Working dir for all client commands: `kapwa-client/`
- React 19 — install `i18next@^25` and `react-i18next@^16` (React 19 compatible); no other i18n libs
- Locale modules are TypeScript objects, statically imported — no runtime `fetch` of locale files (offline-first app)
- Default language is English; `fallbackLng: 'en'`; missing keys log in dev only
- Storage key: `localStorage['kapwa-lang']`; valid values `'en'` | `'fil'`
- `document.documentElement.lang` must be `'en'` or `'fil-PH'` (a11y)
- Server-sent notification titles/messages, user-generated content (remarks, notes, chat, announcement bodies) are NEVER translated
- Existing tests assert English text — they must stay green (English is the default resource)
- Every task ends with a commit; never commit partial work

- [ ] **Step 5: Create i18n init**

Create `kapwa-client/src/i18n/index.ts`:

```ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import en from './locales/en';
import fil from './locales/fil';

export const SUPPORTED_LANGS = ['en', 'fil'] as const;
export type Lang = (typeof SUPPORTED_LANGS)[number];
export const LANG_STORAGE_KEY = 'kapwa-lang';

export function getInitialLang(): Lang {
  const stored = localStorage.getItem(LANG_STORAGE_KEY);
  return stored === 'fil' ? 'fil' : 'en';
}

export function localeLangTag(l: Lang): 'en' | 'fil-PH' {
  return l === 'fil' ? 'fil-PH' : 'en';
}

void i18n.use(initReactI18next).init({
  resources: {
    en: { translation: en },
    fil: { translation: fil },
  },
  lng: getInitialLang(),
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
  returnNull: false,
  missingKeyHandler: (lng, ns, key) => {
    if (import.meta.env.DEV) console.warn(`[i18n] missing key: ${ns}:${key}`);
  },
});

export default i18n;
```

Create `kapwa-client/src/i18n/useLanguage.ts`:

```ts
import { useCallback } from 'react';
import { useTranslation } from 'react-i18next';
import { LANG_STORAGE_KEY, localeLangTag, type Lang } from './index';

export function useLanguage() {
  const { i18n } = useTranslation();

  const lang: Lang = i18n.language === 'fil' ? 'fil' : 'en';

  const setLang = useCallback(
    (l: Lang) => {
      void i18n.changeLanguage(l);
      localStorage.setItem(LANG_STORAGE_KEY, l);
      document.documentElement.lang = localeLangTag(l);
    },
    [i18n],
  );

  return { lang, setLang };
}
```

```ts
  return i18n.language === 'fil' ? 'fil-PH' : 'en-PH';
}

export function formatDate(d: string | Date | null | undefined): string {
  if (!d) return '—';
  return new Date(d).toLocaleDateString(activeLocale());
}

export function formatDateTime(d: string | Date | null | undefined): string {
  if (!d) return '—';
  return new Date(d).toLocaleString(activeLocale(), {
    timeZone: 'Asia/Manila',
  });
}

export function formatTimestamp(iso: string): string {
  const diff = Date.now() - new Date(iso).getTime();
  const mins = Math.floor(diff / 60000);
  const hrs = Math.floor(mins / 60);
  if (mins < 1) return i18n.t('time.justNow');
  if (mins < 60) return i18n.t('time.minutesAgo', { count: mins });
  if (hrs < 24) return i18n.t('time.hoursAgo', { count: hrs, minutes: mins % 60 });
  return i18n.t('time.daysAgo', { count: Math.floor(hrs / 24) });
}
```

```js
import { readFileSync, writeFileSync } from 'node:fs';

const raw = JSON.parse(readFileSync('scripts/i18n-extract/en.json', 'utf8'));
const tree = raw.translation;

function indent(n) { return '  '.repeat(n); }
function emit(obj, depth) {
  const lines = [];
  for (const [k, v] of Object.entries(obj)) {
    if (v && typeof v === 'object' && !Array.isArray(v)) {
      lines.push(`${indent(depth)}${k}: {`);
      lines.push(...emit(v, depth + 1));
      lines.push(`${indent(depth)}},`);
    } else {
      lines.push(`${indent(depth)}${JSON.stringify(k)}: ${JSON.stringify(String(v))},`);
    }
  }
  return lines;
}

const body = emit(tree, 1);
const out = `const en = {\n${body.join('\n')}\n} as const;\n\nexport default en;\nexport type EnLocale = typeof en;\n`;
writeFileSync('src/i18n/locales/en/index.ts', out);
console.log(`wrote ${body.length} key lines to src/i18n/locales/en/index.ts`);
```
