# 20-01 — Coordinator Access Card Management

**Goal:** Coordinator can assign, verify, and log activities on access cards.

---

## Task 1: Backend Permission Updates

**File:** `kapwa-server/src/access-cards/access-cards.controller.ts`

Add `'coordinator'` to `@Roles()` on:
- `POST assign/:beneficiaryId` → `@Roles('admin', 'social_worker', 'coordinator')`
- `GET beneficiary/:id/card/summary` → `@Roles('admin', 'social_worker', 'claimant', 'coordinator')`
- `GET beneficiary/:id/card` → `@Roles('admin', 'social_worker', 'claimant', 'coordinator')`
- `POST log` → `@Roles('admin', 'social_worker', 'coordinator')`
- `GET :cardCode` → `@Roles('admin', 'social_worker', 'claimant', 'coordinator')`
- `GET` (list) → `@Roles('admin', 'social_worker', 'coordinator')`

## Task 2: Migration — logged_by + source_barangay

Add columns to `access_card_service`:
```sql
ALTER TABLE access_card_service
  ADD COLUMN IF NOT EXISTS logged_by UUID REFERENCES users(id),
  ADD COLUMN IF NOT EXISTS source_barangay TEXT;
```

Update `AccessCardService` entity with new columns.

## Task 3: Barangay-Scoped Beneficiary Lookup

**File:** `kapwa-server/src/access-cards/access-cards.service.ts` or add query param

When coordinator assigns a card, filter beneficiary search by `assignedBarangay`.
Ensure ABAC `evaluateBarangayScope` also applies to access card routes.

## Task 4: Coordinator Access Cards Page (Client)

**File:** `kapwa-client/src/pages/CoordinatorAccessCardsPage.tsx`

Three-tab layout:
- **Verify:** code input → fetches card details → shows beneficiary name, barangay, card code, service history table → "Log Activity" button opens inline form
- **Assign:** search beneficiary by name → autocomplete or search results scoped to barangay → shows beneficiary details → "Assign Card" button → shows generated code
- **History:** paginated table of services logged by this coordinator (fetch from `GET /access-cards` with filter)

## Task 5: Log Activity Form

Inline on Verify tab or as modal.

Fields:
- Service type: dropdown (community_service, seminar, distribution, other)
- Service date: date picker (default today)
- Remarks: textarea
- Submit → `POST /access-cards/log` with card code + above fields
