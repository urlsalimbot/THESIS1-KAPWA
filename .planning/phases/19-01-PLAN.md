# 19-01 — Barangay Coordinator Referral System

**Goal:** Coordinator submits referrals → MSWDO reviews → status tracking.

---

## Task 1: Referral Entity + Migration

**Entity** `kapwa-server/src/referrals/referral.entity.ts`:
```typescript
import { Entity, Column, ManyToOne, JoinColumn } from 'typeorm';
import { BaseEntity } from '../common/base.entity';
import { User } from '../users/user.entity';
import { Case } from '../cases/case.entity';

export enum ReferralStatus {
  PENDING = 'pending',
  ACCEPTED = 'accepted',
  DECLINED = 'declined',
}

@Entity({ name: 'referrals' })
export class Referral extends BaseEntity {
  @Column({ name: 'coordinator_id' })
  coordinatorId: string;

  @ManyToOne(() => User)
  @JoinColumn({ name: 'coordinator_id' })
  coordinator?: User;

  @Column()
  barangay: string;

  @Column()
  surname: string;

  @Column({ name: 'first_name' })
  firstName: string;

  @Column({ name: 'middle_name', nullable: true })
  middleName?: string;

  @Column({ nullable: true })
  extension?: string;

  @Column()
  gender: string;

  @Column({ type: 'date' })
  dob: string;

  @Column({ type: 'jsonb', nullable: true })
  address?: Record<string, any>;

  @Column({ nullable: true })
  phone?: string;

  @Column({ type: 'text' })
  reason: string;

  @Column({ type: 'text', default: 'pending' })
  status: ReferralStatus;

  @Column({ name: 'decline_reason', type: 'text', nullable: true })
  declineReason?: string;

  @Column({ name: 'case_id', nullable: true })
  caseId?: string;

  @ManyToOne(() => Case)
  @JoinColumn({ name: 'case_id' })
  case?: Case;
}
```

**Migration:** Add `CREATE TABLE IF NOT EXISTS referrals` with proper FKs.

## Task 2: Referral Module, Service, Controller

**Module** `kapwa-server/src/referrals/referrals.module.ts` — imports TypeOrm for Referral, imports CasesModule and IntakeModule for accept flow.

**Service** `kapwa-server/src/referrals/referrals.service.ts`:
- `create(dto, userId)` — create referral with coordinator_id = userId, barangay from user.assignedBarangay
- `findAll(barangay?, status?)` — admin/social_worker view, filtered
- `findMine(userId)` — coordinator's own referrals
- `findById(id)` — detail
- `accept(id)` — copies referral data into Person, calls intake flow to create beneficiary + household + case, updates referral.status = 'accepted', referral.case_id = new case id
- `decline(id, reason)` — updates referral.status = 'declined', referral.decline_reason = reason

**Controller** `kapwa-server/src/referrals/referrals.controller.ts`:
| Endpoint | Roles | Notes |
|---|---|---|
| `POST /referrals` | coordinator | body validated via zod |
| `GET /referrals` | admin, social_worker | query: barangay, status |
| `GET /referrals/mine` | coordinator | no special query |
| `GET /referrals/:id` | admin, social_worker, coordinator | |
| `PATCH /referrals/:id/accept` | admin, social_worker | triggers intake creation |
| `PATCH /referrals/:id/decline` | admin, social_worker | body: { reason } |

**Zod schemas** `kapwa-server/src/referrals/dto/referrals.zod.ts`.
